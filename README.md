## 🚀 Featured Projects

🔹 **[Cascade Inventory Agents](https://github.com/Oaazu/cascade-inventory-agents)** — Multi-Agent System with Human Oversight

A multi-agent system that compiles a cross-warehouse inventory report in minutes instead of a half-day of manual work — while keeping a human in control. Six worker agents read warehouses in parallel across mixed formats, a synthesizer reasons across them, and a critic agent verifies every finding against source data, catching and correcting the system's own errors before a human approves. Full exchange logging for auditability.

**Stack:** Python · Anthropic Claude · Multi-Agent Orchestration · concurrent.futures

🔹 **[Family Message Helper](https://github.com/Oaazu/family-message-helper)** — Human-Reviewed Multilingual AI Assistant

A Gemini assistant that drafts family messages in English, Spanish, and Haitian Creole for a nonprofit after-school program, built as my AI Tech Corps capstone (OptimaNova AI). Discovery interviews showed translated messages took up to a week, so I designed it to draft all three languages in seconds while a fluent reviewer and the coordinator approve every message. It asks instead of guessing, refuses private details, and ignores hidden instructions. Tested across 12 cases including failures that led to logged fixes, with a full handoff manual for staff.

**Stack:** Google Gemini · Prompt Engineering · LLM Testing · Responsible AI · Technical Documentation

🔹 **[San Pedro Bay Vessel Activity](https://github.com/Oaazu/san-pedro-vessel-activity)** — Maritime Port Analytics with Geofencing

An end-to-end pipeline that turns 10M+ public AIS ship-tracking records from the Ports of LA and Long Beach into 736 reconstructed port visits. Filters out recreational traffic, rebuilds each visit as a timeline of anchorage and berth stops, and geofences 9 anchorage and terminal zones to trace full routes. Every zone is validated against the ships' own reported status — a check that caught and corrected a labeling error before results were shared. Found most ships berth with no wait (median 0 days), while the longest was a tanker anchored 20 days.

**Stack:** Python · DuckDB · pandas · Shapely · Folium · GeoJSON · Parquet

🔹 **[YouTube Research Agent](https://deployagent.streamlit.app/)** — 🌐 Live Demo

An agentic LLM that plans, calls tools in a loop, and synthesizes an answer — built with LangChain. Given a research question, the agent autonomously decides which of three custom tools to call (search, video stats, comparison), chains them in sequence, and reasons over live YouTube data — no hardcoded pipeline. Streamlit chat UI streams the agent's tool calls live. Fully deployed on Streamlit Cloud.

**Stack:** Python · LangChain · Anthropic Claude · YouTube Data API v3 · Streamlit

🔹 **[SmartInventory](https://github.com/Oaazu/case-study-02-smartinventory)** — Demand-Driven Inventory Analytics

End-to-end inventory analytics system analyzing 8,100 sales records across 90 products. Identified weekend demand surges of 1.2x–2.5x baseline and delivered dynamic reorder recommendations replacing a fixed schedule. Delivered with an interactive Streamlit dashboard, business memo, and stakeholder presentation.

**Stack:** Python · SQLAlchemy · SQLite · Streamlit · pandas · Faker
